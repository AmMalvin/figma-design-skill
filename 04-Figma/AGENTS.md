# Figma production scope

Load the applicable installed Figma tool skills before invoking their tools. This repository describes design standards; it does not replace tool-specific prerequisites.

Inspect current file/library/variables/components and available capabilities before mutation. Use existing IDs and bindings, make scoped reversible changes, read back structure and inspect rendered results. Report access/tool limits truthfully. Creating a file or publishing a library follows user scope and actual tool authorization.
