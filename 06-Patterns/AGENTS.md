# Pattern module scope

Patterns orchestrate tasks; components own control behavior. [AI Operating Rules](../00-Core/AI%20Operating%20Rules.md) owns precedence.

Data Entry & Form Patterns.md and Search & Discovery Patterns.md contain pre-existing user edits and remain byte-for-byte unchanged. Read them for supplemental completion/upload and discovery ideas. Current behavioral decisions come from Form Workflows.md and Search Patterns.md. Legacy fixed desktop/mobile compositions, workflow-as-variant lists and invented token names are examples, not project mandates. Accessibility and system promotion follow their shared owners.

Do not translate a task flow into a giant component Type variant or promote business policy into the core system. Preserve scope and permission when describing communication, payment or publication flows.
