# Visual module scope

Shared precedence is defined in [AI Operating Rules](../00-Core/AI%20Operating%20Rules.md).

Iconography.md contains pre-existing user edits and is preserved byte-for-byte during this audit. Read it for construction and asset guidance. Its suggested outlined style, sizes and product stereotypes are examples, not authority over an existing project icon family. Current platform, system, accessibility and task needs govern those choices.

Do not replace project typography, colors, spacing, icons or shape with a reference product's values. Art Direction owns composition; the other modules own their specific visual concerns.
