# Typography

Owns type selection, hierarchy and legibility. Use project fonts/styles first; no universal font, body size or type ratio is prescribed.

Choose roles from information needs: navigation/control labels, reading text, headings, metadata, numerical comparison and expressive display. Limit styles to genuine distinctions; semantic heading structure need not have a one-to-one visual size ladder.

Judge actual rendering: distinguishable characters, available weights, glyph/script coverage, line height, wrapping, fallback and licensing. Avoid stereotyped rules such as "serif for luxury" or "sans for every interface." Type choice should reinforce product character and readability.

Keep long-form measure readable; use logical text alignment and realistic content. Tabular numerals help aligned quantities when the font supports them. Identifiers/code may need differentiated glyphs and a suitable monospace role.

Responsive type preserves hierarchy and text scaling without clipping or shrinking labels to fit. Test translated strings, RTL and scripts with different metrics. Tokenize existing text roles; use shared styles for composite typography and supported variable bindings where appropriate.

Verify small metadata, multi-line labels, mixed scripts, large numbers, fallback loading and actual contrast. [Content Design](../01-Foundation/Content%20Design.md), [Accessibility](../01-Foundation/Accessibility.md), [Token Architecture](../03-Design-Tokens/Token%20Architecture.md)
