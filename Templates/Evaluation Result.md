# Evaluation result

- Scenario, date and context: prompt/fixture versions and relevant files read.
- Generator and evaluator: identities, same author or independent, criteria exposure.
- Output: reviewable artifact path or Figma node, platform and implemented scope.
- Decisions: information model, composition, interaction model, existing-system mapping.
- Evidence: intended, inspected, observed or user validated; checks actually run.
- Critique: all relevant rubric dimensions with evidence and rating; unknowns explicitly marked.
- Findings: severity, confidence, task consequence, repair and verification.
- Stress cases: result per case, distinguishing specified behavior from executed behavior.
- Batch comparison: distinct task structures, any repeated visual formula and reason.
- Outcome: ready for the specified review, revise or blocked; remaining decisions and evidence.

No aggregate score can override a critical failure. Do not promote an author walkthrough to an independent evaluation.
