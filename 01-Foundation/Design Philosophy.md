# Design philosophy

Make product purpose legible through information, behavior and visual language. Restrained and expressive designs both need relevance and refined execution.

Solve the task, respect time/control, preserve an existing system and build only necessary reusable contracts. Familiar controls reduce relearning; original composition and product insight create distinction.

Minimalism fails when it removes comparison context. Scale fails when it generalizes business-specific features. Decoration fails when it obscures hierarchy; purposeful imagery, type and motion can improve character and understanding.
