# Layout system

Owns structural sizing/alignment. [Responsive Design](Responsive%20Design.md) owns adaptation.

Choose regions from the task: editorial measure/rhythm, reconciliation comparison, or tool/content relationships. Do not prescribe desktop columns or sidebars universally.

Use Figma Auto Layout for content flow; define Hug, Fill, fixed, min/max and overflow. Absolute placement fits spatial content/overlays, not missing layout rules. Layout guides support alignment but do not establish responsive behavior.

Specify growing, wrapping, scrolling, anchored and alternate regions. Avoid nested scroll without a task reason. Sticky UI must leave content and focus visible.

Use existing space/dimension tokens. A 4/8-point scale is an example, not authority over the project. When no system exists, establish a small justified foundation.

Verify content extremes, image loading/failure, min/max widths, scaling and locales. [Figma Production](../04-Figma/Figma%20Production.md) owns bindings/readback.
