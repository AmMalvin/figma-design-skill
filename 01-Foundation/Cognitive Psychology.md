# Cognitive psychology

Use cognitive principles as hypotheses, not universal proof.

| Concern | Response | Countercondition |
| --- | --- | --- |
| Working memory | Keep needed context/comparison visible | Every option at once increases search cost |
| Attention | Group relevant information; reduce unrelated alerts | Monitoring can require simultaneous priorities |
| Choice effort | Remove irrelevant choices; disclose advanced work | Hidden frequent controls slow experts |
| Recognition | Use familiar language/controls | Domain mental models differ |
| Confidence | Show state, consequence and recovery | Provisional success that looks final creates false trust |
| Habits | Keep repeated behavior stable | Do not exploit inertia to obtain unwanted consent |

Fitts's/Hick's models explain acquisition/choice costs, not universal sizes, option counts or layouts. [Accessibility](Accessibility.md) owns requirements.

Retain deliberate review for costly actions while removing unnecessary friction. Chunk by meaning and task, not equal decorative cards. Test accuracy, recognition, recovery and time through [Design Research](Design%20Research.md).
