# Jobs to be done

Use when scope or priority is unclear. Frame progress: "When [situation], I want to [progress], so I can [outcome]." This is an analytical frame, not an invented participant quote.

Identify trigger, workaround, functional task, emotional stakes, constraints and success. Ask what users would do without the feature. A job survives the chosen component or technology.

"Reconcile invoice discrepancies without losing source context" points toward aligned records, exception detail and return navigation. "Use a dashboard" names a solution prematurely.

Different roles have different jobs: a customer sending money and an operator investigating failures need different density, authority and feedback. Confirm through [Design Research](Design%20Research.md); prioritize through [Product Thinking](Product%20Thinking.md).
