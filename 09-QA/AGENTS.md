# Quality and evaluation scope

Do not show evaluator acceptance criteria to a generator when measuring independent behavior. Give only the scenario prompt, authorized fixtures and skill entrypoint; use an isolated output folder.

Record observations/artifacts and failure evidence. Static repository validation, author walkthroughs, independent model runs and user studies are different evidence levels. Unknown/unrun must not become pass. A score cannot average away unsafe or inaccessible task blockers.

Evaluation does not authorize live Figma/library mutations, messaging, payments or external publication. Follow the scenario's side-effect boundary and user scope.
